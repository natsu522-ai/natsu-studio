# Natsu Studio — site gratuit

## Ouvrir le site
Double-clique sur `index.html`.

## À modifier en premier
1. Dans `js/script.js`, remplace `TON_EMAIL_ICI@example.com` par ton adresse.
2. Dans `contact.html`, remplace aussi l'adresse e-mail.
3. Remplace les exemples du portfolio par tes vrais travaux.
4. Ajoute tes vrais liens Discord/réseaux.
5. Vérifie les tarifs avant toute mise en vente.

## Important
Le site est une version statique : il fonctionne sans serveur.
Le formulaire de commande ouvre l'application e-mail du visiteur. Pour une vraie boutique/paiement en ligne, il faudra ajouter un service de paiement et vérifier ses conditions, notamment si le vendeur est mineur.
